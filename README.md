# ServiceNow CSA Project — IT Help Desk Workflows

## 📌 Project Overview
A complete IT Help Desk workflow project built on 
ServiceNow Developer Portal for CSA certification.

## ✅ What's Built
- Incident Auto-Assignment Flow
- Service Catalog — New Laptop Request
- Approval Workflow with Flow Designer
- Change Management with CAB approval
- Generic Approval Flow
- SLA Configuration (P1/P2)
- Reports & Dashboard

## 🔧 Tools Used
Flow Designer | Service Catalog | Change Management 
| SLA Engine | Platform Analytics | Scoped Applications
